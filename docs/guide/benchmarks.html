ベンチマーク ​

asyncmux の性能特性を、benchmarks/asyncmux.bench.ts による測定結果とともに示します。 ここに載せる数値は特定の環境での参考値であり、実行環境によって変動します。

測定方法 ​

測定には Vitest のベンチマーク機能を用いています。 各ケースは約 0.5 秒間繰り返し実行され、ops/sec は 1 秒あたりの実行回数を表します。

sh
npx vitest bench --config ./.config/vitest.bench.ts

測定環境は次のとおりです。

  • CPU: 12th Gen Intel Core i9-12900K
  • メモリー: 32 GiB
  • Node.js: v24.15.0
  • 測定日: 2026-09-08

測定結果 ​

待ち行列が存在しない状態での lock / rLock の取得と解放の速度です。

lock / release（キーなし）1,196,7520.0008 ms0.0012 ms
lock / release（キーあり）972,9520.0010 ms0.0020 ms
rLock / release（キーなし）1,181,6290.0008 ms0.0011 ms
rLock / release（キーあり）834,5850.0012 ms0.0015 ms

2 つのワーカーが同一キーに対して取得と解放を繰り返す場合の速度です。

キューで待機中の取得を AbortSignal で取り消す場合の速度です。

H. 現実的な負荷 ​

読み取り 12 件と書き込み 3 件に全体ロック 1 件を混ぜた、キャッシュアクセスを模した負荷での速度です。

ケースops/sec平均p99
読み書き混在アクセス（12R ＋ 3W ＋全体 W）43,3780.0231 ms0.0230 ms

結果の読み方 ​

競合なしのロック取得は 100 万 ops/sec を超えており、通常の非同期処理に付随する排他制御の負荷は無視できる水準にあります。 読み取りロックと書き込みロックの間に大きな速度差はなく、キー指定の有無も結果を大きく変えません。 128 件が同時に殺到するような高い競合下でも 1 件あたり 0.5 ms 程度で処理でき、読み書き混在の現実的な負荷では 4 万 ops/sec を超えています。
